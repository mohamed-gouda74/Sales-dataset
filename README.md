
# Sales Performance Dashboard

## 📌 Project Overview
This project focuses on analyzing sales performance using Microsoft Excel. The dashboard provides an interactive overview of sales, profit, orders, product categories, and regional performance from 2014 to 2017.

The goal is to transform raw sales data into meaningful insights that help understand business performance and support data-driven decision-making.

## 🎯 Project Objectives
- Monitor overall sales and profitability.
- Analyze sales performance across different product categories.
- Compare sales and profit across regions and years.
- Understand the relationship between discounts and profitability.
- Identify the top 5 product sub-categories by sales.
- Present key business metrics through an interactive dashboard.

## 📊 Key Performance Indicators (KPIs)
- **Total Sales:** $2.297M
- **Total Profit:** $286.397K
- **Total Quantity Sold:** 37.873K
- **Average Discount:** 16%
- **Total Orders:** 5,009

## 📈 Dashboard Highlights
- **Category Analysis:** Compare sales, profit, and quantity across product categories.
- **Discount Analysis:** Explore how discount levels relate to average profit.
- **Regional Performance:** Analyze sales and profit by region and year.
- **Top 5 Sub-Categories:** Identify the highest-performing sub-categories by sales.
- **Interactive Visualizations:** Explore business metrics through Excel Pivot Tables, Pivot Charts, and dashboard filters.
